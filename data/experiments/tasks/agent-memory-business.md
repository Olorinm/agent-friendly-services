# 记忆服务：跨会话偏好、更正与遗忘

分类：`agent-tooling/memory`。需求来源于 2026-10-12 打开核实；它们支持场景存在，不证明需求的市场频率。题目中的个人场景与合成材料是设计者的缩小推断，不是来源原话或来源的测试结论。

## 需求与方法

[真实用户的记忆与个性化讨论](https://www.reddit.com/r/AI_Agents/comments/1i7oq4o/how_are_you_handling_memory_and_personalization/)希望应用记住用户并能说明已知信息；这是需求存在的自述，不证明频率。[LongMemEval](https://arxiv.org/abs/2410.10813)区分信息提取、知识更新和未知问题弃答，本题借鉴这些维度，缩成小规模、可独立读回的合成个人资料；不照搬长上下文难度，也不把存储层与执行模型能力混为一谈。[Mem0 的工作流](https://mem0.ai/blog/introducing-mem0)补充偏好存取可行性，只是技术说明。

## 初态与隔离

总控在每次运行前创建不同的合成用户范围。可设置一个无关哨兵用户「只喜欢侦探小说」检测跨用户混入，记录在私有初态；不能在执行者可访问范围里放真实用户。每次重建相同初态、等待服务宣称的写入可见性后独立读回。允许内部记忆表示不同，不强制统一底层记录数量；只比较要求的用户事实与指定删除范围。服务的额外 LLM 提取或 embedding 依赖须冻结并记录，不用不同模型的记忆产品成绩宣称同一纯存储后端优劣。
