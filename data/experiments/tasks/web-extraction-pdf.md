## 需求与方法

[PDF 表格字段提取的用户问题](https://stackoverflow.com/questions/57410061/how-to-extract-data-from-a-table-in-a-pdf-file)（2019）明确希望把 PDF 中指定列逐行取出，供后续数据使用；[个人旅行规划表格讨论](https://www.reddit.com/r/camping/comments/17tpqzg/planning_spreadsheet/)（2023）说明把行程、地点及候选活动整理进可继续编辑的表格有实际用途。这些资料支持需求存在，不证明频率；Zion、EASY 分组和四个字段是本项目结合公开原文所做的小型任务改编，不是原帖原题。

[PubTables-1M（CVPR 2022）](https://www.microsoft.com/en-us/research/publication/pubtables-1m/) 强调表格结构和明确、一致的参考标注。本题仅借鉴把行、列标题和数据对应关系与独立原文核对的方法，不复现其数据集或复杂度，也不把响应长度、调用成功或特定 API 字段当完成标准。

原文从 [NPS Zion 官方出版物页](https://www.nps.gov/zion/planyourvisit/publications.htm) 的 Seasonal Information Guide 取得。冻结 PDF 有两页，约 8.57 MB；其 URL 以 loader.cfm 结尾，但 HTTP 内容类型为 PDF。官方响应文件名为 Summer-Infoguide-2026.pdf，背面印刷发布日期为 5/18/2026，PDF 修改元数据为 2026-07-31；这些标记分别记录，不混称最后在线更新日期。原 PDF、取得元数据、文字提取、视觉核对及期望值仅给验收者，执行者只得到 URL、范围、单位和授权环境。若缓存或源站返回不同版次，先查目标表是否实质变化；仅元数据不同且目标内容相同不另增失败条件。

所选内容为 NPS 署名指南中的短表格事实，未见所选表另列第三方版权。[NPS 使用说明](https://www.nps.gov/aboutus/disclaimer.htm) 将其创作材料一般列为公共领域，但第三方材料及标志有例外。这里只整理少量事实并标明来源，不复制地图、照片、标志或整份指南。原表的难度分组不构成我们对目前开放状态、适合人群或安全性的判断。
