# 数据库接入 v2：连接总控预先提供的专用空数据库

分类：数据库 / 托管关系型数据库（databases/hosted-relational）。

本版本核对普通用户已取得一个专用数据库及连接凭据后，Agent 能否通过指定入口实际接通并保存可复用配置。沿用[既有接入任务](databases-v2.md#接入服务)的连接验证目标，明确将账号、资源创建与凭据准备归于总控；不再要求执行者新建数据库。`database-access-001/v1` 的任务行、冻结输入和评审保持不变，两版本及其准备开销分开记录。
