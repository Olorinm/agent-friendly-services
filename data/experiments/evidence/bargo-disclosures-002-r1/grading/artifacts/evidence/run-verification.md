# 公开核验摘要

数据服务：[Bargo](https://www.bargo.ai/free-apis/congress)。总控依据本次独立验收整理，原始交易行、答案、日志及同期交叉材料私有保留。

`financial-disclosures-002/v1`，独立结论为 `not_completed`。指定服务真实返回了关注名单中的股票查询结果；但执行者处理官方检索结果的批量解析脚本有误，原始文件内容及范围核对没有完成，超时前只有过程叙述，缺少四人最终结论、完整明细和具体原始出处。API 中间结果与独立参考一致，也不能代替未完成的交付。

实际执行约 590 秒触发超时，配置预算为 600 秒并由运行器预留收尾。模型请求用量因中断不完整，执行费用保留未知。独立验收确认当次免 Key、免费只读使用；[免费条款](https://www.bargo.ai/free-apis/terms)要求的署名与数据不重分发边界在本公开摘要保留。

验收输出最初因费用字段结构被录入校验拒绝。总控按验收者原文重排免费规则、观察和证据，并以已有规则原文补入说明字段；没有新增事实、改判或再次调用模型。原始输出、规范化日志及哈希私有留底。

官方独立依据为[年度索引](https://disclosures-clerk.house.gov/public_disc/financial-pdfs/2026FD.zip)及对应 PTR；本次仅验证限定名单、股票和提交月份。无匹配与服务未覆盖必须区分，空响应不能单独证明没有记录。
